# Figure sources

Scripts that generate the paper's figures, plus the rendered figures
(`fig01.png` … `fig14.png`, 600 dpi). Provided for transparency, so the
figures can be reproduced and are demonstrably not fabricated.

- `diag.py`, `figs_a.py`, `figs_b.py` — draw the architecture, pipeline and
  taxonomy diagrams (Figs. 1–12).
- Figures 13–14 (results) are produced by `../code/src/aggregate.py`.

No manuscript text is included in this repository.
